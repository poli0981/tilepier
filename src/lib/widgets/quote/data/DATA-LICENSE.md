# Quote dataset — licence

`quotes.json` is generated by `scripts/quotes-import.mjs` from
[QuoteAtlas](https://github.com/poli0981)'s `data/quotes`. **Do not hand-edit
it**; re-run the script.

Every entry carries a `rights` field, and only three values are allowed to be
bundled here (doc 16 §1):

| `rights`          | What it means                                                           |
| ----------------- | ----------------------------------------------------------------------- |
| `cc0`             | dedicated to the public domain by QuoteAtlas under CC0 1.0              |
| `public-domain`   | the original is out of copyright — proverbs, classics, pre-1929 authors |
| `own-translation` | a translation authored by QuoteAtlas of a public-domain original        |

Entries marked `quoted-with-attribution` are **excluded**, by name, in the
import script. Two exist upstream (both Will Durant, _The Story of Philosophy_,
1926 — in copyright until 2052) and neither is in this file. The script fails
rather than filtering, so a new one appearing upstream stops the import and gets
looked at instead of being silently dropped.

`src/lib/widgets/quote/service.test.ts` asserts the rule again at runtime over
the shipped file, because the import script is run by hand and CI never sees it.

The curation, structure and QuoteAtlas's own translations are **CC0 1.0**.
