# Music fixtures

Generated by `pnpm fixtures:music` (`scripts/gen-music-fixtures.mjs`), which
needs an ffmpeg with libmp3lame, libvorbis and libopus. Committed so tests and
CI never need ffmpeg.

**Nothing here is anyone's recording or artwork.** Every audio file is a sine
tone ffmpeg synthesised, and every picture is a 16×16 block of one colour. The
tags are text written in the script, and they are Vietnamese on purpose.

- `formats/` holds one tagged file per container doc 09 §2 accepts (mp3, m4a,
  flac, ogg, opus, wav), plus the edge cases:
  - `untagged.mp3`
  - `vbr-no-header.mp3`, a VBR stream with no Xing, Info or LAME header
  - `two-covers.mp3`, where the back cover comes before the front
  - `not-audio.mp3`, a text file
- `library/` is a small nested library for scans. It also holds the files a
  scan must pass over:
  - an image
  - a macOS `._` AppleDouble file
  - a `.hidden` folder

What each case measured is in doc 22 §S7.
