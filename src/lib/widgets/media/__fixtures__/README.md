# Media fixtures

Generated by `pnpm fixtures:media` (`scripts/gen-media-fixtures.mjs`), which
needs an ffmpeg with libvpx-vp9, libopus and libx264. Committed, so tests and CI
never need ffmpeg. The script writes only the files it names, so this README
survives a regeneration.

**Nothing here is anyone's film.** Every clip is ffmpeg's own `testsrc2` pattern
at 160×90 over a synthesised sine tone.

- `clip.webm` — VP9 + Opus, 14 s: long enough that "resume after 5 s, unless
  within 5 s of the end" has room.
- `clip.mp4` — H.264 (baseline) + AAC, 14 s, `+faststart`.
- `sound-only.webm` — Opus with no picture: the "no picture this browser can
  show" state.
- `not-video.mp4` — a text file named like a video: error code 4 in every
  browser, the one "unsupported" case they all agree on (doc 22 §S8).
